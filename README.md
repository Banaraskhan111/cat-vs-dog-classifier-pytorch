# 🐾 Cat vs Dog Classifier using PyTorch (Custom Dataset)

A Deep Learning project that classifies images into **Cats** or **Dogs**. This project focuses on building a full pipeline from scratch—starting from a custom dataset to image preprocessing and model evaluation.

## 🚀 Key Features
- **Custom Dataset:** Unlike standard Kaggle sets, this model is trained on a manually curated dataset.
- **Image Processing:** Used **OpenCV** for robust preprocessing (resizing, normalization).
- **Architecture:** Built using **PyTorch** with a Convolutional Neural Network (CNN) approach.
- **Environment:** Developed and trained on **Google Colab**.

## 🛠️ Tech Stack
- **Framework:** PyTorch
- **Computer Vision:** OpenCV (cv2)
- **Data Science:** NumPy, Matplotlib
- **Development:** Python, Google Colab

> **Note on Dataset:** The dataset used for this project is a custom zip file. Due to GitHub's file size limits, the raw images are not uploaded here, but the data loading logic is fully documented in the notebook.

## 📊 Results
The model was trained to identify patterns like dog or cat. display the result using **Matplotlib**.

## ⚙️ How to Run
1. Upload the `DOG_CAT.ipynb` file to Google Colab.
2. Upload your own `train.zip` to the Colab environment.
3. Run all cells to train and test the model.
